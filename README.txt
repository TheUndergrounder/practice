# Telegram-бот «Помощник ГУАП'14»

Удобный инструмент для студентов и сотрудников кафедры, позволяющий быстро узнавать актуальное расписание преподавателей и аудиторий.

---

### Основной функционал
* **Поиск расписания преподавателей:** получение информации о занятиях преподавателя и группах, которые он ведет.
* **Поиск расписания аудиторий:** проверка занятости аудиторий по адресам.
* **Автоматическое обновление:** регулярный сбор актуальных данных с официального сайта университета.

---

### Стек технологий
* **Язык программирования:** Python
* **Фреймворк для бота:** aiogram
* **Парсинг данных:** BeautifulSoup
* **Хранение данных:** JSON-файлы (`shcedule.json`, `shcedule_of_audiences.json`)

---

### Структура проекта
* `bot.py` — основной файл с логикой Telegram-бота, обработкой команд и кнопок.
* `pars.py` — скрипт-парсер для сбора информации о преподавателях и расписании с сайта ГУАП.
* `raspisanie.py` — вспомогательные модули обработки расписания.
* `shcedule.json` / `shcedule_of_audiences.json` — локальные базы данных в формате JSON.
